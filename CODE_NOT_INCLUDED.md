# Code not included

This first public release lets the Find Your Way and Meridian judges and the community review Vela's agreement, design and available evidence before the source code opens. The code will open during the judges' review period under the review-only license in [LICENSE](LICENSE), which permits reading and cloning for evaluation.

# Código no incluido

Esta primera publicación permite que el jurado de Find Your Way y Meridian y la comunidad revisen el acuerdo, el diseño y la evidencia disponible de Vela antes de abrir el código fuente. El código se abrirá durante el periodo de los jueces bajo la licencia de solo revisión de [LICENSE](LICENSE), que permite leerlo y clonarlo para evaluarlo.
